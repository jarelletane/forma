# Forma

An interaction and motion study for a fictional interior-planning product. Forma turns room measurements, budgets, existing belongings, and priorities into a considered furnishing plan.

## Run locally

```bash
npm install
npm run dev
```

## Production checks

```bash
npm run typecheck
npm run build
```

Built with React, TypeScript, Vite, GSAP, ScrollTrigger, and Flip.
